# SO-101 × ACT によるスポンジ仕分けタスク

Physical AI応用1講座 最終課題

## 概要
SO-101ロボットアームとLeRobotを用い、テレオペで収集したデモデータから
ACT（Action Chunking with Transformers）を模倣学習し、
緑色のスポンジを箱に入れるタスクを自律実行させた。

## 動画
https://www.youtube.com/watch?v=DbDuqRO8Ros

## 環境
- ロボット：SO-101（フォロワー／リーダー）
- カメラ：USBカメラ 1台（640×360, 30fps）
- PC：Ubuntu, NVIDIA RTX A5000
- LeRobot：commit 22bd7a2f489b367d8df42de803b1e8c4ca63a3f9

## 実行手順
1. `scripts/env.sh` のポート・IDを環境に合わせて変更
2. データ収集：`scripts/record.sh`
3. 学習：`scripts/train.sh`
4. 推論：`scripts/rollout.sh`

## 結果
- データ：テレオペ 10エピソード（5,609フレーム）
- 学習：ACT 20,000ステップ（バッチサイズ 8、RTX A5000で約20分）、最終loss 約0.13
- 推論：学習済みモデルのみでスポンジを掴んで箱に入れる動作に成功

| 試行 | 結果 | 様子 |
|---|---|---|
| 1 | 成功 | 1回目の把持は空振り。自ら掴み直して箱に入れた |
| 2 | 成功 | 一度で把持し、箱に入れた |
| 3 | 未完了 | 運搬中に箱の手前で落下。掴み直しの途中で記録終了 |

推論時の記録（約60秒）では3回中2回成功。正式な成功率の計測は今後実施する。

詳細は説明資料（`docs/report/`）を参照。

## 工夫点
- **製造現場の仕分け・検品に見立てたタスク設計**：「良品は箱へ、不良品は除外」を想定し、第1段階（箱入れ）から色による仕分けへ段階的に拡張できる設計とした
- **認識しやすい作業環境**：柔らかく掴みやすいスポンジを採用し、濃い色の机と明るい緑でコントラストを確保。カメラの画角・背景・照明を固定した
- **`max_relative_target` の調整（5 → 20）**：5では動きがかくかくして掴めなかったが、20に緩めてACTのチャンク出力に追従できるようにし、把持に成功した
- **再現性を高める環境構築**：`/dev/serial/by-id/` の固定パスでUSBのポート番号入れ替わりを回避。設定を `scripts/env.sh` にまとめ、収録・学習・推論をスクリプト化

## 課題・今後の展望
- データが10エピソードと少なく、位置や向きの変化への対応に限界がある → 40〜50エピソードで本収録し、50,000ステップ程度で本学習
- 白スポンジを加え、色による仕分け（良品は箱へ、不良品は横へ）に拡張し、色別の成功率を評価
- ねじ締めなど精密作業への挑戦、物体検出による工程作業分析との連携
