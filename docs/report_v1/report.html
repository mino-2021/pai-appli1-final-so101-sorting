1. 概要・目的

本課題では、低価格なロボットアーム SO-101 と、模倣学習アルゴリズム ACT（Action Chunking with Transformers）を用いて、緑色のスポンジを掴んで箱に入れるタスクをロボットに自律実行させた。人がリーダーアームでフォロワーアームを操作（テレオペ）してデモデータを集め、そのデータで ACT を学習し、学習済みモデルだけでロボットを動かす。

タスクは、製造現場の仕分け・検品工程（良品を箱へ入れ、不良品を除外する作業）を想定して設計した。第1段階として「良品（緑）を箱に入れる」動作を実現し、第2段階として「不良品（白）は箱に入れず横へよける」仕分けへの拡張を予定している。

タスク机上の緑のスポンジ1個を掴み、半透明の白い箱へ入れる（1エピソードにつきスポンジ1個）
AIの使い方ACT による模倣学習（学習と推論の両方を実施）
想定する応用製造ラインでの部品の仕分け・検品、ピッキング

2. システム構成

2.1 ハードウェア・ソフトウェア

ロボットSO-101 フォロワーアーム＋リーダーアーム（サーボ STS3215、6自由度：肩2・肘・手首2・グリッパー）
電源フォロワー 12V 2A（キット付属）、リーダー 5V
カメラUSBカメラ1台（640×360、30fps、MJPG）。作業領域を斜め上から撮影

フレームワークLeRobot（commit 22bd7a2f）。ROS2 は使わず、Python から USB 経由で直接サーボを制御

2.2 構成図

2.3 ACT の概要

ACT は Stanford の ALOHA プロジェクト（Zhao ら, 2023）で提案された模倣学習アルゴリズムである。カメラ画像と現在の関節角度を入力として、今後の行動をまとめて（チャンク単位で）予測する。1ステップずつ予測する手法に比べ、誤差の蓄積が起きにくく、滑らかな動作が得やすい。

  • 画像エンコーダ：ResNet-18（ImageNet 事前学習）
  • 本体：Transformer エンコーダ（4層）・デコーダ（1層）、CVAE（潜在次元 32）で人のデモのばらつきを扱う
  • 出力：今後 100 ステップ分の目標関節角度（6軸）
  • 損失：行動の L1 損失 ＋ KL ダイバージェンス（重み 10）

3. 手順

  1. キャリブレーション：リーダーとフォロワーを同じ中央姿勢で校正し、角度のずれを防いだ。
  2. データ収集：lerobot-record でリーダーアームを操作し、カメラ画像と関節角度を 30fps で記録した。
  3. 学習：lerobot-train で ACT を学習した。
  4. 推論：lerobot-rollout で学習済みモデルを読み込み、ロボットを自律動作させた。

3.1 データ収集

データセットso101_green_test
エピソード数10（総フレーム数 5,609、1エピソード平均 約19秒）
観測カメラ画像 640×360 ＋ 関節角度 6次元
行動目標関節角度 6次元（リーダーアームの角度）

3.2 学習設定

ステップ数20,000バッチサイズ8
学習率1e-5（バックボーンも 1e-5）チャンクサイズ100
学習時間約20分（RTX A5000）最終 loss約 0.13

3.3 推論設定

lerobot-rollout（episodic モード、1回 40 秒）で実行した。フォロワーの1ステップあたりの移動量上限 max_relative_target は 20 とした（4章・5章を参照）。

4. 結果

学習済みの ACT モデルだけで、ロボットがスポンジを掴み、箱まで運んで離す一連の動作を自律的に実行できた。

試行結果様子
1成功1回目の把持は空振り。自ら掴み直して箱に入れた
2成功一度で把持し、箱に入れた
3未完了把持後、運搬中に箱の手前で落下。掴み直しの途中で記録終了

推論時の記録（約60秒）では 3回中2回、箱に入れることができた。空振りや落下の後に、モデルが自分で掴み直そうとする挙動も見られた。

成功率の正式な計測（例：スポンジの位置を変えた 10 回試行）は今後実施する。また、今回は学習ログを保存していなかったため、loss の推移グラフは掲載していない。

4.1 max_relative_target の調整

当初は安全のため max_relative_target=5 で推論したが、1ステップの移動量が制限されすぎて動きがかくかくし、スポンジを掴めなかった。ACT は 100 ステップ分の行動をまとめて出力するため、ロボットが目標に追いつけないと予測と実際の動きがずれる。20 に緩めたところ、滑らかに動作し把持に成功した。

5. 工夫点（サンプル「SO-101入門」からの発展）

5.1 製造現場の仕分け・検品に見立てたタスク設計

単なるピック＆プレースではなく、「良品は箱へ、不良品は除外」という実際の工程を想定した。第1段階（箱入れ）で動作を確立し、色の違いによる仕分けへ段階的に拡張できる設計とした。

5.2 認識しやすい作業環境の設計

  • 対象物にスポンジを採用：柔らかく形が変わるため、把持位置が多少ずれても掴みやすい
  • 濃い色の机と明るい緑の組み合わせで、対象物と背景のコントラストを高くした
  • カメラの画角・背景・照明を固定し、収録時と推論時の見え方の差を減らした

5.3 動作パラメータの調整

max_relative_target を 5 → 20 と調整し、安全性を保ちつつ ACT のチャンク出力に追従できるようにした（4.1）。

5.4 再現性を高める環境構築

  • USB の抜き差しでデバイス番号（ttyACM）が入れ替わる問題に対し、/dev/serial/by-id/ の固定パスを使用
  • ポート・ID・カメラ設定を scripts/env.sh にまとめ、収録・学習・推論をスクリプト化
  • 使用した LeRobot の commit を固定し、バージョン固有の注意点（推論は lerobot-rollout、データセット名は rollout_ 始まり、カメラは 640×360 のみ対応など）を記録

6. 課題と今後の展望

6.1 課題

  • データ量：10エピソードと少なく、スポンジの位置や向きの変化への対応力に限界がある。運搬中の落下もデータ不足が一因と考えられる。
  • 評価：成功率をまだ定量的に計測できていない。位置を変えた複数回の試行で評価する必要がある。
  • 電源容量：フォロワーの電源（12V 2A）は、複数のサーボに同時に負荷がかかる場面で余裕が小さい。

6.2 今後の展望

  • 緑で 40〜50 エピソードを本収録し、50,000 ステップ程度で本学習して成功率を上げる
  • 白スポンジを加え、色による仕分け（良品は箱へ、不良品は横へ）に拡張し、色別の成功率を評価する
  • ねじ締めなど、より精密な作業への挑戦
  • 物体検出による工程作業分析との連携や、産業用ロボットへの展開
